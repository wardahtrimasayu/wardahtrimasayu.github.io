# Memulai

Panduan ini adalah contoh. Ganti nama produk, domain, data integrasi, dan perintah demo sebelum menerbitkan situs.

## Nama dan domain

Edit `src/config/site.ts`. Atur `name`, `url`, `repository`, dan teks hero untuk setiap bahasa.

## Integrasi

Edit `src/data/integrations.json`. Pertahankan satu entri `id` dan satu entri `en` untuk setiap slug. Gunakan tautan
`https://` dan screenshot opsional di `public/images/`.

## Perintah demo

Tab instalasi membaca `site.install`. Ganti perintah contoh dengan perintah yang benar-benar terdokumentasi untuk
alat Anda. Perintah tersebut ditampilkan sebagai teks dan tidak dijalankan.
